Phase 1 Prerequisite for all

Shared Foundation & Native Vision OCR

Setup workspace dependencies (winit, softbuffer, arboard, slint, objc2-vision), implement native macOS Vision text recognition, clipboard image/text API, and PII redact pipeline.

  • Integrates objc2-vision for VNRecognizeTextRequest on macOS.
  • Creates unified platform::clipboard for RGBA images & text.
  • Implements ocr::pipeline batching redactions with atomic UUIDs.
  • Establishes initial camerashot-cli crate skeleton.
Effort: 1 Day Inspect Spec →
Phase 2 Depends on Phase 1

Interactive Fullscreen Overlay Window

Transform headless overlay test into an interactive, zero-flicker native fullscreen surface with mouse rubber-band drag, 2x magnification Loupe, and clipboard export.

  • winit 0.30 + softbuffer 0.4 borderless topmost window.
  • Retina 2x coordinate mapping without subpixel scaling artifacts.
  • Real 2x pixel magnification Loupe with crosshair & boundary flipping.
  • Keyboard shortcuts: Enter / Cmd+C (Copy), Esc (Cancel).
Effort: 1 Day Inspect Spec →
Phase 3 Depends on Phase 1

Slint Desktop Editor: Image Mode

Connect main_editor.slint to Rust backend. Implement interactive canvas with infinite pan & zoom, 1-click Auto-Redact, OCR extraction, Copy, Save, and Undo/Redo.

  • Wires slint build script and component modules.
  • Infinite Pan & Zoom canvas viewport with centering clipview.
  • 1-Click Auto-Redact triggers Apple Vision + 11 PII Regexes.
  • Atomic Undo/Redo stack integration for redaction blocks.
Effort: 1.5 Days Inspect Spec →
Phase 4 Depends on Phase 3

Slint Editor: Video Mode & Recording

Expand desktop editor with native screen recording loop. Implement interactive multi-track timeline (playback, seek, cut, zoom punch, censor blur) and GIF export.

  • Bounded screen recording loop (10 FPS, 960px width, max 30s).
  • Memory-safe buffer capped at ~650MB without disk stalls.
  • Interactive timeline: Play/Pause scrubber, cuts, cubic smoothstep zoom.
  • Direct multi-threaded animated GIF export via native gifski.
Effort: 1 Day Inspect Spec →
Phase 5 Depends on Phase 1

CLI Capture Utility (ariashot)

Implement fast command-line capture binary ariashot using clap 4. Support full display, crop bounds, clipboard copy, text OCR, and fail-closed Auto-Redact.

  • Flags: --full, --crop <X,Y,W,H>, -o <path>, --clipboard.
  • --ocr: prints extracted text to stdout or copies to clipboard.
  • --redact: automatically masks sensitive PII before saving/copying.
  • Fail-closed security: halts export if OCR pipeline errors out.
Effort: 0.75 Day Inspect Spec →
